## 📌 Project Overview
This is a modern, fully responsive, and accessible personal portfolio website built using vanilla **HTML5**, **CSS3**, and **JavaScript**. It highlights background information, technical skills, featured internship projects, and contact avenues.

### 🌟 Key Features
- **Semantic HTML5 Architecture:** Clean layout using `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, and `<footer>`.
- **Modern Responsive Design:** Flexbox & CSS Grid with fluid media queries optimized across mobile, tablet, and desktop screens.
- **Theme Customization:** Interactive Dark / Light Mode switcher with `localStorage` persistence.
- **Micro-Interactions & Glassmorphism:** Glass-effect cards, smooth hover animations, and dynamic gradient accents.
- **Performance Focused:** Vanilla CSS & JS with zero heavy external runtime dependencies for instant page loads.

---

## 🛠️ Technologies Used
- **HTML5:** Semantic structure and accessibility.
- **CSS3:** Custom properties (CSS variables), Flexbox, CSS Grid, Glassmorphism, Responsive Media Queries.
- **JavaScript (ES6):** Theme toggling, active scroll spy, mobile drawer navigation.
- **Icons & Typography:** Font Awesome 6 & Google Fonts (Inter, Outfit).

## 💻 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/axediqbal/safeXinterntask1.git
   ```

2. **Navigate into the project directory:**
   ```bash
   cd safeXinterntask1
   ```

3. **Open with Live Server:**
   - Open the directory in **VS Code**.
   - Right-click `index.html` and select **"Open with Live Server"**.
